# 3D asset pipeline handoff

The [art fidelity catalog](../../previews/art-fidelity/README.md) records surface and geometry passes across the 22 original GLBs. Run the generator and checker from the catalog to reproduce the material outputs. Blender 4.3.2 reimported every surface candidate and geometry rework. The original art remains available for direct visual comparison.

The [Catacombs review](../../previews/art-fidelity/catacombs/README.md) includes reproduction commands and per-mesh reports. All eight additional exports passed a Blender 4.3.2 round trip, bounds checks and checks for tangents and UVs on normal-mapped primitives. The renders use matching cameras and lights. Use the original assets to compare outlines, weak points and attachment locations during rigging.

The [Buried Forest review](../../previews/art-fidelity/buried-forest/README.md) includes reproduction commands and results for the seven landmarks and mechanisms. The exported GLBs preserve node names, hierarchy, local transforms and pivot properties. The source and revised models passed the same targeted Blender geometry and pose checks.

Resolve UV projection seams, surface scale and the high mesh counts before engine integration. Verify Unreal material import, tangent basis, static clearances, skeletal rig and LOD budgets. Use the same close-up geometry and material review for the Lost Mines roster.

The [Mine Borer study](../../previews/lost-mines/README.md) adds a 3.01 m static mesh for the floor-21 charge encounter. The generator reimports the GLB and checks the nine pivots, exposed rear chitin and normal-mapped tangents. Use the height and the roughly 4.18 m visual width when reviewing clearance around the forelimbs. The combat hit zones and sweep dimensions still need in-engine verification.

The game consumes four pivot-local GLBs generated by `scripts/creatures/export_mine_borer_parts.py`. Blender verified the vertex positions in the rest and recovery poses after reimport. The game source bundle includes hashes, actor-relative pivots, local mesh bounds and the rear plate rotation for the Unreal import step.
